# 区域AE＋All-attention gross：已完成三模型的检测结果

2026-09-13 UTC。Qwen2.5、LLaVA、InternVL均已完成各4000图、72个正式检测头；Qwen3仍在提取，本报告不包含它。

原3200/800图片划分、所有mentions、seeds43/44/45；以下均为三seed均值±总体标准差，HALL-AUPR以幻觉为正类。单层MLP/XGB仅训练内2560/640图选参，未使用测试集选择超参数。

V=[AE_V,log1p(SV_all)]；VP=[AE_VP,log1p(SV_all+SP_all)]；G=[AE_G,log1p(SG_all)]；VP+G拼接VP与G完整两块。每块取全部层；AE各区域独立归一化attention并做区域MAD gate，VP重新计算AE，不是AE_V+AE_P。gross复用真实RMS All-attention K32，逐token响应取范数再相加。

三层MLP=[128,64,32]、BN/dropout0.3、固定原训练协议；单层为sklearn12候选，XGB18候选。单层/三层还有优化和正则等差异，不能只归因于深度。

已完成部分：36种拼接×分类器组合相对AE-only均提高AUROC，其中33种提高HALL-AUPR。单层MLP的12种融合组AUROC全部低于三层（下降0.40至5.13个百分点）；XGB的VP+G在三模型均优于同输入三层，但不是所有组都胜出。仅视觉组换All-attention路径后，相对旧Visual-only没有一致提升。
