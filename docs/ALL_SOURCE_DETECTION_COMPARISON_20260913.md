# 幻觉检测：15 组特征定义、完整结果与历史对照

2026-09-13。读取已有检测结果与特征矩阵完成比较，没有重新训练、改变特征或在测试集选参。

本轮没有获得跨模型一致的检测提升。B1-F6 对 F0 的三 seed 均值在 LLaVA、Qwen3、InternVL 略有提高，Qwen2.5 降低；四模型两项指标的配对 95% 区间均跨零。与历史较强的强度融合比较，B1-F6 也不是统一领先。B2 分数完整保留，但 K4 特征未通过全量积分复核，不能据此确认方法优势。

## 统计口径与可比范围

- 各模型原 4000 图、3200/800 图片划分，全部 50,812 mentions；不是上一份机制报告的 500 图/100 测试图，也不排除检测 mentions 中的标签冲突。
- 固定 MLP [128,64,32]、BatchNorm、dropout .3、Adam lr .001、weight decay 1e-5、batch 256、最多 100 epochs；训练 loss 调度与早停，最低训练 loss checkpoint，seeds 43/44/45，无标准化。NaN 固定置零。
- AUROC 与 HALL-AUPR 越高越好。HALL-AUPR 用 HALL 为正类；不是数量占优的 REAL-AUPR。分类器保存 REAL 概率时，相应使用 1−p_REAL 计算 HALL 指标。
- 主表统一为逐 seed 指标的均值 ± 总体标准差（ddof=0），不是概率 ensemble，也不是 95% 区间。不同模型的 HALL 比例不同，AP 更适合在同模型内比较。
- 当前 F0 与旧 full-prefix `gated_raw_concat` 的特征与结果均直接复用。其余历史 fixed-three-hidden 采用同一固定 MLP 协议；XGB/单层 MLP/RF另有训练内搜参，不能将分类器差异当成纯特征消融。
- 已按模型核验当前矩阵与旧 gate、S、对应融合、跨尺度融合、visual-only F 的 mention ID 顺序、标签和 ntrain 完全一致，核验全部 15 组维度与 F0 特征矩阵。详见[对齐数据](../outputs/ffn_all_source_paths_v1/detection_comparison_20260913/alignment_validation.json)。这验证比较口径，不等于修复旧数值尾部误差。

## 每一组到底输入什么

所有标量沿全部 decoder 层拼接，不是先跨层平均。层数 L 分别为 28/32/36/32。方括号表示向量拼接。

P=prompt（含 BOS/模板/特殊 token），V=visual，G=目标前可见生成前缀。令 U_g 为组内 attention×gate 的和，a_m 为 token attention write。All-attention 路径的向量响应记 e_m，来源和为 A_g=Σa_m、E_g=Σe_m。

| 组 | 具体输入 | 总维度 |
|---|---|---:|
| F0 | [U_P, U_G, U_V]，全因果前缀 gate，原值区域和，不除 token 数、不重归一化 | 3L |
| F1_raw | P/V/G 各自 [gross, net, group_gain]，共 9 个逐层字段 | 9L |
| F1_log1p | F1 的 6 个 gross/net 取 log1p，3 个 gain 保持原值 | 9L |
| F2 | 三来源组旋转、三对输出余弦及 Δcos、视觉上下文两指标、三组内部 κ、组间 κ，详见下表 | 15L |
| B1-F3_raw | B1 的 [‖E_R‖, ‖E_P‖, ‖E_V‖, ‖E_G‖, residual_share] | 5L |
| B1-F3_log1p | 上行 4 个响应范数取 log1p，residual_share 不变 | 5L |
| B1-F4 | B1 的 3 个残差—来源余弦、G−V平衡、attention—residual κ、2 个残差余弦变化 | 7L |
| B1-F5 | [F2, B1-F4]，All-attention 几何＋B1 残差几何 | 22L |
| B1-F6 | [F0, F2, B1-F4]，attention×gate＋上述几何 | 25L |
| B2-F3_raw | B2 的 [‖C_R‖, ‖C_P‖, ‖C_V‖, ‖C_G‖, residual_share] | 5L |
| B2-F3_log1p | 上行 4 个响应范数取 log1p，residual_share 不变 | 5L |
| B2-F4 | 与 B1-F4 对应的 7 个字段，全部使用 B2 路径响应/输入定义 | 7L |
| B2-F5 | [F2, B2-F4] | 22L |
| B2-F6 | [F0, F2, B2-F4] | 25L |
| length | [N_G, response_index]；当前实现两列相等，无逐层复制 | 2 |

**F5/F6 没有拼入 F1/F3。** 特别是 F6 没有直接输入任何贡献范数、group_gain 或 residual_share；它是 attention×gate 与几何的融合，不是“所有提取信号的融合”。逐 token 标量、三组 token 数、单独的输入 cos 也没有全部进入这 15 组。输入 cos 通过 Δcos 间接参与；只有 length 单独输入生成长度。没有 B1+B2 联合组。

### F1 的 9 个字段

每个 g∈{P,V,G}：gross_g=Σ_m‖e_m‖，net_g=‖Σ_m e_m‖，group_gain_g=net_g/‖A_g‖。gain 是净向量范数比，不能解释为每个 token 都乘同一个正标量。`log1p` 对零值定义良好；它只改变幅度编码，不是标准化。

### F2 的 15 个字段

| 字段族 | 具体定义 | 每层数量 |
|---|---|---:|
| 来源自身旋转 | cos(A_P,E_P)、cos(A_V,E_V)、cos(A_G,E_G) | 3 |
| 来源之间输出余弦 | cos(E_V,E_G)、cos(E_V,E_P)、cos(E_P,E_G) | 3 |
| 来源之间余弦变化 | 对应输出余弦减 cos(A_i,A_j) | 3 |
| 视觉上下文调制 | cos(E_V^vis,E_V^all)、‖E_V^all−E_V^vis‖/‖E_V^vis‖ | 2 |
| 组内 κ | 每个 g 的 net_g/gross_g | 3 |
| 三来源组间 κ | ‖E_P+E_V+E_G‖/(‖E_P‖+‖E_V‖+‖E_G‖) | 1 |

### B1/B2 的 F3 与 F4

B1 用真实 Norm+FFN 路径 b_O+α(r+A_P+A_V+A_G)，输入几何使用原始 r/A_g；B2 用冻结 clean endpoint RMS 缩放后的方向，在纯 FFN 的 αn 路径积分。B2 的输入几何使用冻结归一化后的来源。

令 H_R/H_P/H_V/H_G 分别表示对应版本的来源响应，H_A=H_P+H_V+H_G：

- F3 的 residual_share = ‖H_R‖/(‖H_R‖+‖H_A‖)，不是除以四来源范数之和。attention_total_norm 虽然保存，但不是 F3 的独立输入。
- F4 前三项：cos(H_R,H_V)、cos(H_R,H_P)、cos(H_R,H_G)。
- 第四项 balance：cos(H_R,H_G)−cos(H_R,H_V)。
- 第五项 κ_AR：‖H_R+H_A‖/(‖H_R‖+‖H_A‖)。
- 最后两项：R–V、R–G 的输出余弦分别减对应版本的输入余弦。
- B2 bias 参与原归因与闭合检查，但 bias norm 没有单独进入 F3/F4；不能从“五个归因来源”推断检测头输入了五个来源范数。

F6 的实际维度是 700/800/900/800，F0 为 84/96/108/96；固定隐藏层没有随输入维度增加而调参，因此差异同时涉及特征及固定头面对更高维输入的表现。

## 历史特征如何对应

旧来源强度 S_g=Σ_{j∈g}‖c_j‖，来自完整来源冻结 RMS 的 K50 分解。它与本次 All-attention F1 的 e_m 不是同一路径，也与 B2-F3 的 ‖Σ_j c_j‖ 不同：前者为 gross，后者为 net；旧三组 S 单独输入不含 residual。不能把它们当作同一个特征重复命名。

旧 visual-only F=[AE,log1p(S_E)]，S_E 是旧视觉条件路径 e_m 的范数总和；AE 是视觉内部归一化 attention 对语义 gate 的加权均值。它与 full-prefix 的 U_V 在归一化、gate 参考范围上都不同。旧 [U,S] 为三来源全部拼接；旧跨尺度 VP/G 组为 [U_V+U_P,log1p(S_V+S_P),U_G,log1p(S_G)]，不是三来源分别保留。

**历史口径修正：** `outputs/ffn_source_composition_v1/summary.md` 及其 detection.csv 用的是 ensemble 指标。本报告从每模型 detection.json 的 seed_mean_std 读取旧 F，避免拿 ensemble 和三 seed 均值比较。例如 Qwen2.5 旧 F 的 ensemble AUROC 88.21%，三 seed 均值是 87.45%；LLaVA 90.50% 对 90.02%，Qwen3 89.65% 对 88.65%，InternVL 86.38% 对 85.83%。这些是不同统计，不是旧实验成绩被改动。

## 如何读本轮结果

1. **F1：强度有检测信息，但不普遍优于 gate。** F1_raw 的 AUROC 在 Qwen2.5 低于 F0，其他三模型接近；AP 只有 InternVL 高于 F0。F1_log1p 在四模型 AUROC 都低于 raw，AP 仅 Qwen2.5 提高。不能从旧 S 的经验推断本次强度取 log 一定有利。
2. **F2：几何能检测，增量并不统一。** 四模型 AUROC 为 85.64/89.43/89.85/87.40%，明显高于 length 的点估计；但对 F0 的 AP 仅 InternVL 更高。F2 没有独立预注册 bootstrap 对照，不能据这些点估计宣称显著优势。
3. **B1-F3：残差/attention 范数与份额单独使用并不强。** Raw 在 Qwen3/InternVL AUROC 略高于 F0，AP 四模型均低于 F0。Log1p 相对 raw 四模型双指标下降；Qwen3/InternVL 尤其明显。该结论限定于当前固定无标准化 MLP，不能归结为 norm 信息在原理上无用。
4. **B1-F4：残差几何单独输入，四模型双指标都低于 F0。** 机制曲线有差异，不保证这组特征的检测效果更强。
5. **B1-F5/F6：加入 gate 后 AUROC 四模型均比 F5 提高，AP 除 Qwen2.5 外提高。** 与 F0 比，F6 的 AUROC 差为 −1.89/+.31/+.85/+.27 点，AP 差为 −3.01/+.32/+2.05/+2.70 点；8 个配对区间都跨零。F5 在 Qwen2.5 的 AUROC 甚至低于 F0 且该预注册区间全负（约 −5.36 至 −.48 点）。
6. **B2：保留分数，不确认增益。** 当前 F6 的 AP 四模型均高于 F0，表面上也高于 B1-F6；但全量 K4 积分失败，必须修复后才能判断来源几何是否真的更有效。不能把较好分类分数反过来当作数值正确的证明。
7. **长度控制：强度/几何不仅在点估计上高于长度。** 预注册的 B1-F5/F6 相对 length 在四模型两指标的配对区间均为正。不过这不等于做过条件于长度的独立信息检验；尚未训练 length+各特征对照或做等长度匹配。

## 与之前较强结果比较

- **Qwen2.5：**本次 B1-F6 85.58/45.18，低于旧 log1p(U) 三来源 88.03/49.34；没有替代它的性能依据。对旧 visual-only F，AUROC 也降低，AP 略高，属于取舍。
- **LLaVA：**本次 B1-F6 89.86/69.68，低于旧 [U,S] 三来源的 90.48/72.19；也低于旧 visual-only F 的 90.02/70.82。即便 B2-F6 的近似分数也未超过该旧融合组。
- **Qwen3：**B1-F6 90.76/68.98 高于旧 visual-only F 88.65/62.83，也高于旧 U 原值；但对旧 [log1p(U),log1p(S)] 的 90.88/68.97，AUROC 略低、AP 几乎相同。旧跨尺度 XGB 为 91.00/69.65，不过分类器不同。

上面都是明确命名的既有组，没有据本次测试分数重新选择特征或参数。它们并非“所有历史方法的独立验证冠军”；重复查看同一 800 图测试集不能提供新数据上的确认。

预注册 bootstrap 中，B1-F6 相对 F0 的 8 个区间均跨零；相对旧 source_raw 的 8 个也均跨零。相对 source_log1p，只有 InternVL 的 AP 区间完全为正（+4.09 点，[+.34,+7.69]），不能推广为所有对照、所有模型都提升。区间未作跨多组比较的多重校正。
