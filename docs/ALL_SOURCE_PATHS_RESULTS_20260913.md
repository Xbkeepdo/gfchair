# All-attention / B1 / B2：正式结果复核与分析（2026-09-13）

**运行已全部结束，但B2数值验收未通过。** B1和All-attention积分在全量数据上稳定；B1尚无稳健优于F0的检测证据。B2的表面提升来自未收敛的K4近似特征，目前不能用来认定B2优于B1或attention基线。

本次仅读取已有分片、预测、曲线和bootstrap进行复核，没有重新训练或修改原实验结果。发现的B2问题不是随机seed波动，也不能归于原生精度来源重构误差。

B2-F6在四模型的两项点估计都高于F0。原K4结果中，InternVL HALL-AUPR增量为+4.43个百分点，[+0.37,+8.12]；其他三模型该增量区间均跨零，四模型AUROC增量区间也都跨零。但B2数值未通过，这些是**特定K4近似特征的观测成绩**，不能直接解释成已验证B2分解的优势。B2与B1的胜负需要精度修复后的对照。

长度控制明显弱于B1-F5/F6，四模型两项指标的相关配对区间均为正；这表明这些组合特征含有位置以外的预测信息，但不能因此认定单个机制指标已排除全部长度混杂。N_G和response_index在此实现中相等。

强度log1p没有带来一致收益：F1的AUROC在四模型全部下降约0.46–1.04个百分点；B1-F3的AUROC和HALL-AUPR也均下降，InternVL约-3.19/-6.08个百分点。该结论限定在当前不标准化的固定MLP协议下，不推广为log1p通常无效。

名义95%区间没有多重比较校正；测试集亦已用于多个历史实验，不能把探索性比较写成新的独立确认。

## 4. 机制结果：目前可保留的三个观察

以下使用共享500图，先在同一图片内计算HALL−REAL，再对同时具有两类目标的图片等权平均。统计量按层展示，不把层当作独立显著性样本。

| 模型 | 视觉上下文变化 HALL更大层数（all/test） | 视觉–生成输出余弦 HALL更高层数（all/test） | B1残差生成–视觉平衡 HALL更低层数（all/test） |
|---|---:|---:|---:|
| Qwen2.5 | 25/28 / 19/28 | 26/28 / 23/28 | 26/28 / 23/28 |
| LLaVA | 27/32 / 28/32 | 19/32 / 23/32 | 26/32 / 28/32 |
| Qwen3 | 31/36 / 32/36 | 26/36 / 29/36 | 36/36 / 35/36 |
| InternVL | 30/32 / 27/32 | 29/32 / 24/32 | 32/32 / 30/32 |

**观察一：HALL的视觉响应对路径上下文变化更敏感。** 四模型多数层的visual_context_relative_change更大，visual_context_cos更低；但整体余弦仍约0.98，方向变化并非普遍大幅翻转。更适合描述为“上下文调制增强”，尚不是因果解释。

**观察二：没有支持“幻觉时视觉和生成来源更加冲突”的简单假设。** cos(E_V,E_G)在HALL中反而通常更高，跨层平均同图配对差约+0.035至+0.072。余弦更高不等于视觉证据更正确，也不能据此证明FFN造成幻觉。

**观察三：B1的残差平衡在HALL中偏向视觉一侧，而非生成一侧。** 指标cos(E_R,E_G)−cos(E_R,E_V)的配对差在四模型整体为负。这里的“偏向”仅指相对方向关系，不是信息来源份额；residual也不等于language prior。

B1的residual share层均值约0.495–0.544、attention–residual kappa约0.16–0.31，说明它的分量常常强烈抵消。一个需要防止的解释错误是，把径向路径的几何约束直接当作幻觉特有机制：当E_R约等于−E_A时，范数份额自然接近1/2。当前REAL/HALL在这些量上的差异也没有统一方向。

B2残差几何曲线虽已生成，本报告不据其K4数值推出机制结论。

## 5. 后续修正顺序

1. 扩展数值审计到所有decoder层；对已发现的问题层增加目标覆盖。不能再次只选5层，也不能只看中位误差。
2. 对B2独立比较K8/16/32/64和更高精度参考，同时检查组向量响应、纯积分闭合及来源重构误差；用审计决定足够的K，必要时采用自适应，不能直接假定K64已足够。
3. 正式提取及训练入口加入数值验收门槛，失败明确阻止进入检测；保留原结果作为K4近似对照。
4. 复用All-attention/Visual/B1已有结果，只重新捕获并补算B2所需组向量，重训B2相关五组×三seed×四模型（60头），刷新涉及B2的bootstrap和汇总。
5. 在上述修正前，不以B2的当前表面优势选择论文主方法。可保留的研究线索是视觉上下文调制及更高的视觉–生成对齐，后续在独立数据上验证。
