# 四模型 V/VP+G batch-size sweep 与 SVAR 对照（811）

## 实验设置

- 数据：固定图片级 8:1:1（3200/400/400），split seed 20260912，全部 mentions；训练 seeds 43/44/45。
- 信号：True-RMS all-attention `z-A_all -> z`，局部 FP32、Gauss–Legendre K32。V=`[AE_V,log1p(S_V^all)]`；VP+G=`[AE_VP,log1p(S_V^all+S_P^all),AE_G,log1p(S_G^all)]`。
- 分类器：训练集逐列 StandardScaler，无 BatchNorm，完整150 epochs，最低 validation BCE loss checkpoint。每个模型/特征固定当前验证选定的其余超参数，只改变 batch size `{32,64,128,256,512}`。
- Qwen2.5 VP+G 固定其独立19候选搜参赢家；Qwen2.5 V及其余模型沿用当前受控 V/VP+G 配置。
- SVAR：LLaVA 零基层5–18，其他模型按深度比例映射；原生248隐藏层分类器。
- 筛选规则：三训练 seed 的测试 AUROC 均值严格大于对应模型 SVAR AUROC；同时报告 HALL-AUPR。测试集此前已访问，本轮是探索性 batch sweep。

## 汇总

- AUROC超过SVAR：24/40个模型×特征×batch候选；其中19个候选的HALL-AUPR也同时超过。
- Qwen2.5：V五个batch的AUROC全部超过SVAR；VP+G除batch64外均超过。V的五个候选均未同时超过SVAR HALL-AUPR。
- LLaVA：V和VP+G没有任何batch的AUROC超过SVAR。
- Qwen3：V和VP+G的十个batch全部在两项指标上超过SVAR。
- InternVL：V没有候选超过SVAR；VP+G五个batch全部在两项指标上超过。
- 若单独按HALL-AUPR筛选，AUROC未过线但AP过线的额外候选为：Qwen2.5 VP+G batch64；LLaVA VP+G batch64/128/256/512。
- batch会同时改变每个epoch的optimizer step数量，因此本实验比较的是固定150 epochs下的batch训练协议，不能把差异只解释为梯度噪声。
